# Prueba-Cultura-Digital-
para Cultura Digital

### Descripción del Programa

Este programa en C++ evalúa si una persona cumple con ciertos requisitos educativos y de experiencia para ser “aprobado” o “rechazado”.


### Funcionamiento
Solicitud de nivel de estudio:
El programa pide al usuario que ingrese su nivel de educación eligiendo un número:
1 → Primaria
2 → Secundaria
3 → Universitario
Después, solicita ingresar la cantidad de años de experiencia laboral o práctica que tiene el usuario.


### Evaluación de condiciones:
El programa determina el resultado según estas reglas:
Aprobado si el usuario tiene nivel universitario (3) y 5 o más años de experiencia.
Aprobado si el usuario tiene nivel secundario (2) y entre 3 y 5 años de experiencia.
Rechazado si la experiencia es menos de 3 años, sin importar el nivel.
Sin requisitos si no se cumple ninguna de las condiciones anteriores.
Salida:
Muestra en pantalla el resultado: "Aprobado", "Rechazado" o "Sin requisitos" según corresponda.
